Nykaa – Descriptive Analytics Project

This project focuses on analyzing Nykaa-style sales data to understand order trends, purchase category performance, regional demand, and customer satisfaction. Using data visualization and descriptive analytics, the report explores daily order volume, Gross Merchandise Value (GMV), state-wise sales performance, order success rates, seller activity, and weekday versus weekend purchasing patterns. The analysis is based on a synthetically generated dataset and demonstrates how data analytics can support business insights and decision-making.

IBM Cognos Analytics – Retail Sales Dashboard

This project focuses on analyzing retail sales data using IBM Cognos Analytics. It includes creating list reports, grouped reports, crosstab reports, and interactive prompt reports to analyze sales performance. The project uses fields such as region, store name, product category, quantity, sales amount, and order ID to organize data, apply filters, and generate meaningful business insights through reporting and visualization.
